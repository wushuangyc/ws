# MOBIUS 战报海报风格

后续做海报时，以本文件和 `references/mobius-fire-hero.png` 为唯一视觉基准。不要换成扁平插画、商务渐变或写实摄影风。

## 参考图

- 文件：[`references/mobius-fire-hero.png`](./references/mobius-fire-hero.png)
- 比例：竖版 **2:3**（参考图 1024×1536）
- 品牌：底部横幅 **MOBIUS**
- 用途：销售 / 业绩战报、超额达成、历史新高类庆祝海报

## 版式（从上到下）

1. **顶部三行标题**（金色书法，右上区域略偏右）
   - 第 1 行最大：成就定性，如「历史新高」
   - 第 2 行：周期 / 类型，如「月度超额」
   - 第 3 行：品类 / 渠道，如「WIFI超额」
2. **中央主数字**：超大号指标 + 单位，盖在人物胸口位置，如「169单」
3. **人物**：哪吒式少年战神立于画面中轴，火焰与红绫环绕
4. **底部弧形横幅**：暗红底 + 金色无衬线品牌名 `MOBIUS`

文字全部叠在人物前方；人物叠在火焰前方。

## 视觉语言

| 项目 | 要求 |
| --- | --- |
| 气质 | 国漫燃向、史诗、庆祝、压迫感 |
| 主色 | 深红、焰橙、金黄、近黑烟色 |
| 文字材质 | 锤箔金 / 金箔裂纹，颗粒、火星、磨损，不要纯平金色 |
| 字体 | 中文用厚重笔刷书法体；品牌名用粗无衬线大写 |
| 光效 | 背后火焰主光 + 人物轮廓火光；满屏火星、余烬、烟尘 |
| 人物 | 红肤、橙瞳、长发向上扬、肩扛长枪/火尖枪、红绫飞舞 |

## 可替换槽位

生成新海报时只改这些字段，其余构图、材质、人物姿势保持同一套模板：

```json
{
  "template": "mobius-fire-hero",
  "aspect": "2:3",
  "headlines": ["历史新高", "月度超额", "WIFI超额"],
  "metric": { "value": "169", "unit": "单" },
  "brand": "MOBIUS"
}
```

- `headlines`：固定三行，由重到轻；不要改成四行或段落。
- `metric.value`：主视觉，数字尽量短（2–4 位）。
- `metric.unit`：紧贴数字，如「单」「台」「万」。
- `brand`：默认 `MOBIUS`，放在底部弧形横幅正中。

## 出图约束

- 竖版 2:3，至少 1024×1536；需要印刷时放大，不要改横版。
- 主数字必须是画面最大元素，一眼能读。
- 中文标题保持书法金箔，不要改成细黑体或英文衬线。
- 不要加入二维码、小字免责、水印网格或多余 logo。
- 人物保持哪吒式少年战神，不要换成真人、西装、吉祥物。
